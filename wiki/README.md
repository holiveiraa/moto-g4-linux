# Wiki source

`pages.json` maps canonical public documents to GitHub Wiki page names.
`_Sidebar.md` and `_Footer.md` are navigation templates. Generate the pages with
`scripts/export-wiki.py`; do not edit an exported copy as a separate manual.

See [Wiki setup](../docs/wiki.md). Export is local-only and does not create a
GitHub repository, initialize a remote Wiki or push any changes.
